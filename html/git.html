Git

  • git init - инициализация репозитория.
  • git clone ссылка с GitHub - клонирование удаленного репозитория на свой компьютер.
  • git add - добавление файла в отслеживаемые.
  • git status - проверка изменений.
  • git commit -m "описание операции" - создание коммита. Коммит показывает Git, что файл был изменен.
  • git push - внесение изменений на удаленный репозиторий.
