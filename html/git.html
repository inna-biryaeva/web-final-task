Git

  • git init - инициализация репозитория.
  • git clone ссылка с GitHub - клонирование удаленного репозитория на локальный компьютер.
  • git add - добавление файла в отслеживаемые.
  • git status - проверка изменений.
  • git commit -m "описание операции" - создание коммита. Коммит показывает Git, что файл был изменен.
  • git push - внесение изменений на удаленный репозиторий.
  • git pull - получение изменений из удаленного репозитория на локальный компьютер.
  • git branch название ветки - создание ветки.
  • git checkout название ветки - переход на ветку.
  • git log - просмотр истории коммитов в репозитории.
